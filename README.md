🚚 Supply Chain Analytics & Performance Dashboard

An end-to-end Supply Chain Analytics project developed using Python, MySQL, and Microsoft Power BI. This project demonstrates the complete data analytics workflow, from data cleaning and SQL analysis to designing an interactive Power BI dashboard that provides actionable business insights.

📌 Project Objective

The objective of this project is to analyze supply chain operations and identify valuable insights related to:

Sales Performance
Profitability
Customer Segments
Product Categories
Shipping Efficiency
Regional & Market Performance

The dashboard helps decision-makers monitor KPIs and improve supply chain performance through data-driven decisions.
